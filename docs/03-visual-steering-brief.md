# Visual Steering Brief

## Chosen Direction

Engineering Notebook × Modern AI Laboratory

## Intended Feeling

The website should feel fun and friendly while remaining grounded in real engineering concepts.

## What We Want

- A distinct personality
- Technical credibility
- A well-structured knowledge base
- A sense of experimentation
- Lifelong learning

## What We Do Not Want

- Excessive gradients
- Neon effects everywhere
- Meaningless animations
- A cluttered layout
- A generic corporate-template appearance

## Colour Direction

Warm Notebook

| Role | Colour | Hex code |
|---|---|---|
| Main background | Warm ivory | `#F7F4EA` |
| Main text | Ink navy | `#172A3A` |
| Primary accent | Teal | `#0F766E` |
| Playful accent | Apricot | `#E8895A` |
| Content surface | Soft white | `#FFFDF7` |
| Borders | Warm grey | `#D8D3C5` |

## Typography Direction

### Primary Font

Source Sans 3 will be used for headings, navigation and body content. It should make the portfolio feel friendly, modern and readable.

### Technical Accent Font

JetBrains Mono will be used sparingly for project statuses, technical metadata, code and small engineering labels.

### Typography Guardrails

- Do not use Times New Roman.
- Do not use the monospace font for long paragraphs.
- Use no more than two font families.
- Maintain readable font sizes and sufficient line spacing.
- Provide system-font fallbacks if the web fonts cannot load.
