# Resume and Contact Page Brief

## Purpose

The page will provide a concise professional overview and safe ways to learn more about my work or contact me.

## Public Information

- Professional title and engineering direction
- High-level experience summary
- Core technologies
- Selected projects
- Education and certifications
- GitHub profile
- Medium profile
- LinkedIn profile
- Dedicated public email, if created

## Private Information

The public website and downloadable files must not expose:

- Phone number
- Home address
- Identification or passport numbers
- Date of birth
- Private email addresses
- Immigration documents or sensitive visa information
- References and their contact information
- Confidential employer or customer information

## V1 Approach

The website will first contain a web-based professional summary.

A downloadable résumé may be added later only after a separate redacted version has been reviewed for privacy, accuracy and metadata.

## Contact Guardrail

Do not create a contact form until there is a justified backend, spam protection, input validation and privacy policy. For V1, use reviewed professional links.
